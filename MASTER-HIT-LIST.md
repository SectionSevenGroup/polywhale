- Each item must have a clear status: **Backlog**, **Ready**, **In Progress**, **Blocked**, **Review**, or **Done**.
- Material design or UX decisions must reference the applicable shared standards for this product family.
- No item is **Done** without completion evidence.
- If chat guidance conflicts with GitHub, GitHub governs until this file or the relevant issue is deliberately updated.
