# polywhale — Completion Evidence

> A task is not complete because someone says it is complete. This ledger records verifiable evidence that accepted work was implemented and checked.

## Evidence standard
For every completed item, record:
- **Work item:** link or exact reference to the master hit list / GitHub issue.
- **Result:** what changed.
- **Commit / PR:** immutable GitHub reference where possible.
- **Validation:** tests, screenshots, device checks, build output, deployed URL, or other direct proof.
- **Date:** completion date.
- **Residual risk:** anything still unverified or intentionally deferred.
