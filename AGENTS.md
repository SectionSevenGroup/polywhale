## Shared app design context

At the start of app work, use the [Paddock Context Governor](.agents/skills/paddock-context-governor/SKILL.md) and [Dieter Rams Design](.agents/skills/dieter-rams-design/SKILL.md), including Rams’ ten-principle reference. For changes that affect what people see or do, also use [Paddock Design](.agents/skills/paddock-design/SKILL.md), [Apple UX/UI](.agents/skills/apple-ux-ui/SKILL.md), and [Paddock Ive Design](.agents/skills/paddock-ive-design/SKILL.md). Check the current Apple HIG sections for the affected flow, the approved product profile, and the rendered result. Apply the relevant guidance and preserve existing product and domain requirements.

The [design context manifest](.agents/design-context.json) pins this package and its file hashes. Update the shared files together from their canonical revision.
